## 📌 Descripción

**BitZone** es un proyecto web desarrollado como parte de una actividad educativa, con el propósito de **compartir conocimientos básicos sobre hardware y componentes informáticos con estudiantes de primeros años**.

El proyecto fue utilizado durante las clases para presentar de una manera **visual, sencilla e interactiva** diferentes componentes de una computadora y explicar su función dentro del sistema.

La página reúne información sobre elementos fundamentales como **procesador, memoria RAM, tarjeta madre, GPU, almacenamiento, fuente de poder, sistema de refrigeración y puertos de conexión**.

---

## 🎯 Objetivos

* 🧠 Explicar conceptos básicos relacionados con el hardware.
* 💻 Dar a conocer los principales componentes de una computadora.
* 📚 Facilitar el aprendizaje mediante contenido visual.
* 🖥️ Utilizar el desarrollo web como herramienta educativa.
* 👨‍🏫 Apoyar las actividades de enseñanza dirigidas a estudiantes de primeros años.
* 🌐 Crear una experiencia de consulta sencilla e intuitiva.

## 🌐 Desarrollo Web

El proyecto fue desarrollado mediante **HTML**, creando diferentes páginas dedicadas a cada tema.

La estructura permite separar la información por categorías y facilitar la navegación entre los diferentes componentes del hardware.

## 👨‍🏫 Aplicación educativa

Uno de los objetivos principales de **BitZone** fue utilizar el desarrollo de software como una herramienta para **transmitir conocimientos tecnológicos**.

El proyecto permitió presentar conceptos de hardware de una forma más accesible para estudiantes que estaban comenzando su formación, relacionando la teoría con elementos que pueden encontrar físicamente en una computadora.
